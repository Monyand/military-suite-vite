# Виправлення після перевірки коду

## Галочки ПБД

- Файл єдиного бекапу для передачі іншому користувачу не містить `reportedInPbd`, включно з вкладеною історією.
- При відновленні для того самого ID залишаються галочки цього комп’ютера. Значення зі старих вхідних бекапів також ігноруються.
- Нові записи отримують «не подано». Інші поля запису оновлюються з файлу.
- Відновлення замінює базу, а не зливає її. Попередній перегляд показує кількість нових і відсутніх ID.
- Внутрішня зашифрована копія «Попередній стан» зберігає власні галочки для відкату після збою. Вона залишається у браузері та не є файлом обміну.

## Сумісність і відкат

Формат журналу залишається `version: 1`. Додана ревізія `schemaRevision: 1` лише заповнює відсутні локальні галочки. ID, дати та зміст не переписуються. Старі файли читаються без їх зміни; невідома майбутня ревізія відхиляється до запису даних.

Вихідний код до правок збережений окремо:
`C:\Users\lebed\OneDrive\Desktop\Втрати противника\.review-backup-20260928`

Для відкату коду закрийте програму, поверніть відповідні файли з цієї копії та заново виконайте `npm run build:single`. Базу браузера це не відновлює і не очищає. Нові допоміжні файли після повернення старих імпортів не використовуються; видаляти їх для відкату не потрібно.

## Перевірки

Додано `tests/suite-review-regressions.cjs`: обмін за кілька днів, локальні галочки, чисте відновлення, старі бекапи, відкат при збої, міграція, перевірка цілісності, новий медичний тип, статуси донесень, екранування HTML і пагінація.

`tests/suite-review-ui.cjs` перевіряє інтерфейс у новому ізольованому браузерному контексті без доступу до робочої бази. Типовий шлях — `dist-single/MilitarySuite.html`; можна задати `SUITE_TEST_URL`.

Створення «200 від ран» та відсутність автозбереження чернеток залишені без змін відповідно до прохання користувача.

Перевірено: сім цільових логічних тестів, контроль походження вихідного HTML, два браузерні сценарії на автономному HTML та збірка `build:single`. Браузерні сценарії включали реальні натискання кнопок, формування звіту, збереження фільтрів, попередній перегляд відновлення та штучний збій запису пакета. Усі завершилися успішно. Повний набір усіх старих тестів не запускався.
